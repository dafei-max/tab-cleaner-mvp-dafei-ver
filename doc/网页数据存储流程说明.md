# 网页数据存储流程说明

## 功能：自动提取并存储网页 OpenGraph 数据

| 功能 | 前端入口/表现+描述 | 关联脚本 | 执行顺序 |
|------|-------------------|---------|---------|
| **自动提取网页数据** | **触发时机：**<br>1. 页面加载完成（`document.readyState === 'complete'`）<br>2. SPA 路由变化（通过 `MutationObserver` 监听）<br>3. 用户手动触发清理操作<br><br>**提取内容：**<br>- 页面标题（`<title>` 或 OG/Twitter meta）<br>- 页面描述（OG/Twitter description）<br>- 页面图片（优先 OG/Twitter image，否则智能选择最佳图片）<br>- 站点名称（OG site_name）<br>- 当前 URL（规范化后存储） | `opengraph_local_v2.js`<br>`content.js`<br>`eagle_storage.js` | 1. 页面加载完成<br>↓<br>2. `extractOpenGraphEnhanced()` 开始提取<br>↓<br>3. 检查 `document.hidden`，等待 tab 激活（如需要）<br>↓<br>4. 提取 meta 标签（OG/Twitter）<br>↓<br>5. 智能选择最佳图片<br>↓<br>6. 下载图片转为 Data URL（最多等待 2 秒）<br>↓<br>7. 保存到 IndexedDB |

## 数据流总结

### 1. **页面加载时（自动提取）**
```
页面加载 → opengraph_local_v2.js → 提取 OG 数据 → 下载图片 → 保存到 IndexedDB
```

### 2. **用户触发清理时（完整流程）**
```
用户点击按钮 → background.js → 激活所有 tab → 串行收集 OG 数据 → 
发送到后端 → 生成 embedding → 存储到 PostgreSQL → 
触发 caption 生成任务 → 异步生成 caption → 更新数据库和 IndexedDB → 
保存到 chrome.storage.local → 打开 PersonalSpace 显示
```

### 3. **数据存储位置**
- **IndexedDB**: 图片原始数据（dataUrl, thumbnail, colors）
- **PostgreSQL**: 结构化数据（title, description, embedding, caption）
- **chrome.storage.local**: Session 历史记录（用于 PersonalSpace 显示）

### 4. **数据同步机制**
- **实时同步**: WebSocket 推送 caption 更新
- **批量同步**: PersonalSpace 定期查询 `/api/v1/search/batch-captions` 获取最新 caption
- **CDN 兜底**: 如果图片 URL 失效，使用 IndexedDB 中的 dataUrl
